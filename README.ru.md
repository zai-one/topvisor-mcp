# Topvisor MCP

**Работайте с семантикой и историей позиций из чата.**

> MCP-сервер для Topvisor: сохранённые позиции, ядро запросов, AI-трекер и платные съёмы позиций только после расчёта цены и в пределах бюджета.

Попросите ассистента разобрать проект, подготовить группы ключевых слов или найти запросы, потерявшие позиции в сохранённых отчётах. Topvisor MCP работает с вашими проектами и позволяет предварительно просмотреть поддерживаемые изменения.

[Установка](#установка) · [Подключение к ассистенту](#подключение-к-ассистенту) · [Issues](https://github.com/zai-one/topvisor-mcp/issues)

Например, попросите ассистента:

> Сравни сохранённые позиции моего проекта на две выбранные мной даты. Найди запросы с падением и сгруппируй их по целевым URL.

## Что можно сделать

| Задача | Возможности MCP |
|---|---|
| Разобрать проект | Проекты, папки, группы, ключевые слова и настройки поиска. |
| Организовать семантику | Создание групп, импорт фраз, назначение целевых URL и тегов с предпросмотром поддерживаемых операций записи. |
| Разобрать динамику | Чтение сохранённой истории позиций по настроенным в проекте регионам поиска, в том числе только по запросам с SERP-фичами, например AI Overview (`serp_features`). |
| Следить за ИИ-ответами | Настройки ИИ-Трекера, сводка упоминаний, видимости и тональности, история по промптам (`topvisor_ai_tracker_*`). Платные проверки ИИ-Трекера не запускаются. |

Новые сценарии: `topvisor_rank_changes` сравнивает позиции и релевантные URL за две даты и выгружает JSON/CSV. Для платной проверки доступны оценка стоимости, подтверждённый запуск и просмотр состояния; проекты и лимиты задаёт оператор. [Примеры и настройка](docs/RANKINGS.md#русский).

## Почему этот MCP

- Ленивая загрузка инструментов (опционально): `TOPVISOR_TOOL_LOADING=lazy` (или выбор в мастере настройки) — старт с небольшим ядром, наборы включаются по запросу; см. [Ленивая загрузка инструментов](#ленивая-загрузка-инструментов).
- Чтение использует сохранённые данные и бесплатно; платный съём требует `topvisor_balance` → `topvisor_check_quote` → подтверждения в пределах лимитов проектов и стоимости.
- Наборы инструментов по умолчанию (meta, positions, ai_tracker, checks, setup_write) и режим только чтения; запись сначала показывается как превью. Opt-in: `semantics` (сбор фраз, частотность, проверка релевантности, индексация, дедупликация, прогресс кластеризации), `analytics` (`topvisor_report`) и `competitors_write`. Платные запуски `topvisor_semantics_launch` и изменения конкурентов требуют `approval_id`, подтверждённого оператором вне MCP (`operator_command` из ответа: `topvisor-approval --path STATE_DB --approval-id ID --digest D --accept` или `--config` с файлом настроек сервера; одноразовый, привязан к аккаунту, пользователю Topvisor, вызывающему и точному запросу с проектом, 30 минут, хранится в базе состояния). Платные запуски семантики учитываются в `TOPVISOR_CHECK_DAILY_BUDGET` вместе с платными съёмами позиций; запуск с неизвестным исходом блокирует новые платные задачи проекта до `topvisor-check-reconcile --check-id TASK_ID`, повтор того же approval возвращает сохранённый ответ. Изменения конкурентов проходят через постоянный журнал идемпотентности.
- Сравнения и выгрузки позиций отличают отсутствующие значения от позиций (JSON/CSV).
- У других Topvisor MCP на GitHub ([SCom-82/topvisor-mcp](https://github.com/SCom-82/topvisor-mcp), [psilon2000/topvisor-mcp](https://github.com/psilon2000/topvisor-mcp)) нет CI; psilon2000 защищает запись флагом `confirm=true`, но без расчёта цены и лимита бюджета.

Добавление конкурента: `topvisor_competitors_write(action="add", project_id=7, url="example.org", name="Example")`.
Один конкурент на вызов; опционально `brand_name`, `service_name` (`positions` / `aiTracker`) и `brand_aliases`.
Прежние `urls`/`names` допустимы только с одним элементом. Массивы с несколькими элементами, конфликтующие
скалярные/массивные значения и `brand_names` отклоняются до approval. После обновления подготовьте новый approval.

## Ленивая загрузка инструментов

Ленивая загрузка инструментов (опционально): `TOPVISOR_TOOL_LOADING=lazy` стартует с небольшим ядром и `topvisor_enable_toolsets`, остальные наборы включаются по запросу (`tools/list_changed`). Стоимость старта (tools/list + instructions, ≈символы/4): eager ≈5561 токенов, lazy ≈1196 токенов (−78%). По умолчанию `eager` — без изменений; если клиент не поддерживает `tools/list_changed`, оставьте `eager` или переподключитесь после включения. Область: включение действует в пределах MCP-сессии (session visibility FastMCP), включённые одним клиентом наборы не видны другому. HTTP-транспорт здесь stateless (каждый запрос — отдельная сессия), поэтому включение там не сохраняется: для общего HTTP используйте `eager` или `TOPVISOR_TOOLSETS`.

Клиенты и `notifications/tools/list_changed` (проверено по официальной документации, changelog или заявлениям мейнтейнеров, 2026-10):

| Клиент | `tools/list_changed` | Источник |
|---|---|---|
| Claude Code | Да (интерактивно: tools, prompts, resources; `-p`/Agent SDK: только tools) | [docs: Dynamic tool updates](https://code.claude.com/docs/en/mcp) |
| VS Code (GitHub Copilot) | Да (dynamic tool discovery); новые инструменты могут стать доступны агенту только со следующего хода | [docs](https://code.visualstudio.com/api/extension-guides/ai/mcp), [#303012](https://github.com/microsoft/vscode/issues/303012) |
| Gemini CLI | Да (обновляет реестр инструментов) | [PR #14375](https://github.com/google-gemini/gemini-cli/pull/14375), [PR #21050](https://github.com/google-gemini/gemini-cli/pull/21050) |
| Cursor | Ненадёжно: регрессия в 3.12.x подтверждена командой Cursor; после включения перезапустите Cursor | [forum](https://forum.cursor.com/t/mcp-server-regression-does-not-reload-tools-disconnect-does-nothing-ignores-mcp-json-changes-etc/166216) |
| Claude Desktop, Windsurf, Codex CLI, Cline, Zed, Continue | Не проверено: официальных данных нет; используйте `eager` или переподключитесь после включения | — |

## Поддержка и обновления

- Проект активно поддерживает ZAI.ONE: текущая версия 0.6.0; изменения в [CHANGELOG.md](CHANGELOG.md) и [Releases](https://github.com/zai-one/topvisor-mcp/releases).
- Встроенная проверка обновлений: попросите ассистента вызвать `topvisor_check_update` (публичный GitHub API, без учётных данных, с кэшем; ничего не устанавливается автоматически; отключение: `TOPVISOR_DISABLE_UPDATE_CHECK=1`).
- Следует актуальным практикам MCP: аннотации инструментов (read-only / destructive), наборы инструментов и режим только чтения, `instructions` сервера, промпты и ресурсы, структурированные ошибки с подсказками, секреты не попадают в ответы, бюджет токенов описаний проверяется в тестах.
- CI прогоняет тесты на Linux и Windows для каждого pull request.

## Установка

Хотите установить готовый пакет? [Установка релиза и создание конфигурации клиента](INSTALL.md#install-a-release-package) работают без клонирования исходников.

Нужны **Python 3.12–3.14** и [uv](https://docs.astral.sh/uv/getting-started/installation/). Можно клонировать проект через Git или [скачать ZIP](https://github.com/zai-one/topvisor-mcp/archive/refs/heads/main.zip). Для ZIP откройте распакованный каталог и пропустите первые две команды.

Нужны ID пользователя Topvisor и API-ключ. Настройщик сохраняет ключ в приватном локальном файле.

```sh
git clone https://github.com/zai-one/topvisor-mcp.git
cd topvisor-mcp
uv sync --frozen
uv run --frozen python scripts/configure.py
uv run --frozen topvisor-mcp --config mcp.local.json --check-config
```

Настройщик создаёт локальную конфигурацию и сохраняет секреты в приватных файлах. Если конфигурация уже существует, он не перезапишет её. `--check-config` проверяет локальные настройки; доступ к аккаунту проверяется первым запросом ниже.

## Подключение к ассистенту

Добавьте конфигурацию в MCP-клиент, использующий раздел `mcpServers` (например, Claude Desktop или Cursor). Замените `/ABSOLUTE/PATH/` своим абсолютным путём; на Windows в JSON можно использовать `D:/Tools/`.

```json
{
  "mcpServers": {
    "topvisor": {
      "command": "uv",
      "args": [
        "--directory",
        "/ABSOLUTE/PATH/topvisor-mcp",
        "run",
        "--frozen",
        "topvisor-mcp",
        "--config",
        "/ABSOLUTE/PATH/topvisor-mcp/mcp.local.json"
      ]
    }
  }
}
```

Клиент сам запускает MCP-сервер. После обновления списка инструментов отправьте первый запрос. Для другого формата конфигурации используйте те же `command` и `args`; `uv` должен быть доступен процессу клиента.

### Первый запрос

> Покажи мои проекты Topvisor. Для выбранного проекта покажи регионы поиска и группы ключевых слов.

Вы увидите проекты и их текущие настройки. После этого можно запросить сохранённые позиции или подготовить изменение семантики. Предпросмотр не меняет данные проекта.

Если инструменты не появились, проверьте абсолютный путь, доступность `uv` и результат `--check-config`. Для ошибки доступа проверьте учётные данные и права аккаунта. [Подробная установка и диагностика](INSTALL.md).

## Управление доступом и ограничения

Отчёты читают уже сохранённую историю Topvisor. Платные проверки проходят отдельный сценарий оценки и подтверждения; по умолчанию они отключены до настройки проектов и лимитов оператором. Изменения ключевых фраз начинаются с предпросмотра. Удаление данных недоступно. [Ограничения и сверка результата](docs/RANKINGS.md#русский).

### Обновления

`topvisor_check_update` сравнивает установленную версию с последним [релизом на GitHub](https://github.com/zai-one/topvisor-mcp/releases) и возвращает ссылку на релиз и команду `uv tool install --force ...`. Сам MCP ничего не устанавливает. Результат кешируется на 24 часа рядом с базой состояния; если в кеше есть более новая версия, сервер один раз упомянет её в инструкциях. `TOPVISOR_DISABLE_UPDATE_CHECK=1` отключает и сетевой запрос инструмента, и обновление кеша при запуске.

Для работы по сети предусмотрен HTTP с проверкой токенов. [Настройка HTTP](INSTALL.md#http), [конфигурация и права](docs/RUNTIME.md), [подключение Python-пакета](INSTALL.md#python-package-and-platform-integration).
